## Import

```python
import thrindex.encoders as enc
```

All encoders produce a tensor of shape `[T, *input_shape]` with values in {0.0, 1.0}. THRINDEX uses **time-first** convention throughout.

---

## enc.rate

Bernoulli spike encoder. Each element of the input is treated as a firing probability and sampled independently at each timestep.

```python
spikes = enc.rate(
    x: torch.Tensor,                # [batch, *], values in [0, 1]
    T: int,
    generator: torch.Generator,    # explicit, required
) -> torch.Tensor                   # [T, batch, *], binary
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `x` | `Tensor` | Input values, clamped to `[0, 1]` before sampling. |
| `T` | `int` | Number of timesteps to generate. |
| `generator` | `torch.Generator` | Explicit RNG. This function never touches global torch RNG state. |

The `generator` is **required** - there is no optional seed shortcut. Construct and seed it in the calling scope:

```python
import torch
import thrindex.encoders as enc

gen = torch.Generator()
gen.manual_seed(42)

x = torch.rand(32, 700)        # 32 samples, 700 features
spikes = enc.rate(x, T=100, generator=gen)
# spikes: [100, 32, 700], binary
```

**Behavior:** `spike[t, b, i] ~ Bernoulli(x[b, i])` independently for each t. The expected firing rate of feature i is exactly `x[b, i]`.

## enc.latency

Deterministic time-to-first-spike encoder. Higher input values fire earlier; lower values fire later or not at all.

```python
spikes = enc.latency(
    x: torch.Tensor,   # [batch, *], values in [0, 1]
    T: int,
) -> torch.Tensor       # [T, batch, *], binary
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `x` | `Tensor` | Input values, clamped to `[0, 1]`. |
| `T` | `int` | Number of timesteps. |

**Behavior:** spike time is `floor((1 - x) * T)`, clamped to `[0, T)`. A value of 1.0 fires at t=0; a value of 0.0 never fires within T timesteps. Each feature fires at most once. No RNG is used.

```python
spikes = enc.latency(x, T=100)
# spikes: [100, 32, 700], binary - each spatial location fires at most once
```

---

## enc.delta

Deterministic change encoder. Fires when the absolute change in the input from one timestep to the next exceeds a threshold.

```python
spikes = enc.delta(
    x: torch.Tensor,          # [T, batch, *]
    T: int,
    threshold: float = 0.1,
) -> torch.Tensor              # [T, batch, *], binary
```

**Parameters**

| Name | Type | Default | Description |
|---|---|---|---|
| `x` | `Tensor[T, batch, *]` | - | Time-series input. `x.shape[0]` must equal `T`. |
| `T` | `int` | - | Expected number of timesteps. |
| `threshold` | `float` | `0.1` | Minimum absolute change required to fire. |

**Behavior:** `spike[t] = 1` where `|x[t] - x[t-1]| > threshold`. At t=0 the reference is zeros. No RNG is used. Raises `ValueError` if `x.shape[0] != T`.

```python
# x is a time-series of sensor values: [T, batch, n_features]
spikes = enc.delta(x, T=x.shape[0], threshold=0.05)
```

## Encoder comparison

| Encoder | Information | Deterministic | Input shape |
|---|---|---|---|
| `rate` | Mean firing rate | No (requires generator) | `[batch, *]` |
| `latency` | Spike timing | Yes | `[batch, *]` |
| `delta` | Change detection | Yes | `[T, batch, *]` |

For pre-encoded spike datasets (SHD, N-MNIST, DVS Gesture, CIFAR10-DVS), the THRINDEX app handles encoding internally. The encoders module is for custom value datasets loaded via Own values.
