## Import

```python
import thrindex.train as thx_train
```

The canonical training loop:

```python
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

for x, labels in dataloader:
    # x: [T, batch, in_features]
    spikes = model(x)                          # [T, batch, n_classes]
    loss = thx_train.rate_loss(spikes, labels)
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()
```

## thx_train.rate_loss

Cross-entropy loss on mean firing rates. The canonical objective for THRINDEX classifiers.

```python
loss = thx_train.rate_loss(
    spikes: torch.Tensor,   # [T, batch, n_classes]
    labels: torch.Tensor,   # [batch], long
) -> torch.Tensor            # scalar, differentiable
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `spikes` | `Tensor[T, batch, n]` | Output spike raster from the model. Time-first. |
| `labels` | `Tensor[batch]` | Integer class labels. |

**Behavior**

Averages spike counts over the time dimension, then applies standard cross-entropy:

```python
mean_rates = spikes.mean(dim=0)   # [batch, n_classes]
loss = F.cross_entropy(mean_rates, labels)
```

The output neurons compete to fire the most across the T timesteps. The neuron with the highest mean rate is the prediction. This is equivalent to treating mean rates as unnormalized logits.

**Reference:** Eshraghian et al. (2023). "Training Spiking Neural Networks Using Lessons From Deep Learning." Proc. IEEE, 111(9), 1016-1054.

## thx_train.accuracy

Classification accuracy from a spike raster.

```python
acc = thx_train.accuracy(
    spikes: torch.Tensor,   # [T, batch, n_classes]
    labels: torch.Tensor,   # [batch], long
) -> float
```

Returns the fraction of samples where the argmax of mean firing rates matches the target label. Not differentiable - use `rate_loss` for the training objective.

```python
with torch.no_grad():
    spikes = model(x_val)
    acc = thx_train.accuracy(spikes, y_val)
    print(f"val_acc={acc:.4f}")
```

An empty batch returns `float("nan")`.

## thx_train.count_correct

Integer count of correctly classified samples. Used internally by `accuracy`.

```python
n = thx_train.count_correct(
    spikes: torch.Tensor,   # [T, batch, n_classes]
    labels: torch.Tensor,   # [batch], long
) -> int
```

The prediction for each sample is the output neuron with the highest mean firing rate over T.
