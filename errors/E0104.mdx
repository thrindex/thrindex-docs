<Warning>E0104: target has no native delay support and emulation is disabled</Warning>

## What happened

The model sets `delay` above 0 on a Dense layer, but the compilation target declares `native_delay_max_steps=0` and `delay_fallback="reject"`. The target cannot implement delays at all, and no fallback is configured.

## Why

The simulator emulates delays. This error is raised when a descriptor says it has no delay steps and its fallback is `reject`.

## How to fix

1. **Compile with the default call**: `thx.compile(model, "model.thx")`. The simulator emulates delays.
2. **Remove the lag**: construct the dense layer with `delay=0`, which is the default.

## Example

```
E0104: target has no native delay support and emulation is disabled in layer 0
Why: this target's capability descriptor declares native_delay_max_steps=0 and delay_fallback="reject".
Fix: use the "sim" target (which emulates delays via ring buffers), or remove delays from the model.
Docs: https://docs.thrindex.com/errors/E0104
```
