<Warning>E0207: backend execution error on sample N</Warning>

## What happened

During a conformance run, one sample failed. The harness reports that sample index and stops collecting a result for it.

## Why

The detail string is the error from that sample. The artifact or that input is the place to look.

## How to fix

1. Run that sample on its own, outside the harness.
2. Read the detail field.
3. Fix the artifact or the input, then run the suite again.

## Example

```
E0207: backend execution error on sample 34: <detail>
Why: the backend-under-test returned an error during the conformance run
Fix: check the backend driver and the artifact compatibility
Docs: https://docs.thrindex.com/errors/E0207
```
