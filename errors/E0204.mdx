<Warning>E0204: backend execution failed</Warning>

## What happened

The artifact parsed, and the input shape was accepted, but the run failed. The detail line is the simulator's reason.

## Why

The failure is in the detail string. Typical causes are a bad artifact, an input that does not match the model, or an internal simulator error.

## How to fix

1. Read the detail line.
2. Check the artifact with `thrindex doctor --check model.thx`.
3. Re-run with `thrindex run model.thx`.

## Example

```
E0204: backend execution failed
Why: <detail from the simulator>
Fix: read the detail and correct the artifact or the input
Docs: https://docs.thrindex.com/errors/E0204
```
